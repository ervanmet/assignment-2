# Homework 2 | Assignment

## Purpose

This assignment will help you understand the MVC model and how to implement it into an application.

## Project Overview

This project is a simple MVC-style web application that demonstrates how content can be organized into separate model, view, and controller responsibilities. The site includes a navigation bar with four links, and each link displays its own page content in the main content area without reloading the entire page.

## Instructions

1. If you do not understand what MVC is or how to use it, watch the class lectures and read the articles posted in the Homework 2 overview.
2. You will be creating an application that is set up the way shown in class for a simple MVC project.
3. Make sure you use npm to create your project and that you have a package.json file.
4. You need to create four links in the navigation that, when clicked, display that page's information in the content area of the site. When a link is clicked, the current page information should disappear, and the selected page information should appear in its place.
5. You can create any page design you like, but you must have four pages, and they must contain images and text. Lorem ipsum text is acceptable.
6. Upload this project to the Web 4 server and to GitHub as well. Remember to add the link to Web 4 in this README file.
7. Submit the GitHub link for this assignment.

## Project Requirements

- MVC structure implemented in a simple application
- Working navigation with four links
- Four pages with text and images
- Main content area updates dynamically based on the selected page
